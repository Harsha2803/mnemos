Three real bugs D1 found and fixed — read TRACKER's 2026-08-22 notes before assuming any
of this area is untouched infrastructure:

  1. Keycloak's dev-mode storage has no persistent volume. Any container recreation (a
     normal `docker compose down && up`) minted fresh random subject UUIDs for the three
     seeded users, permanently breaking every already-provisioned login. Fixed by pinning
     explicit `id` fields in `deploy/keycloak/mnemos-realm.json` — do not remove them, and
     pin a new one if a seeded user is ever added.
  2. `mnemosctl connector register` claimed to be "idempotent per slug" but crashed with a
     raw `IntegrityError` traceback on a retry. Fixed by checking `get_by_slug` first.
  3. `SqlToolRepository.list_tools`/`list_invocations` sorted by a non-unique column alone
     (`name`, `created_at`) with no tiebreak, so Postgres could answer the identical query
     differently across executions once more than one row tied — an intermittent MCP
     authorization denial that only reproduced on a *second* full Playwright run in one
     session. Fixed by adding `id` (UUIDv7) as an explicit tiebreak. The same latent shape
     exists in `features/knowledge/adapters/repository.py`'s document list
     (`created_at DESC` alone) — deliberately left unfixed, no test or failure demonstrates
     it yet, but it is the same class of bug if a future feature reads that list positionally.
